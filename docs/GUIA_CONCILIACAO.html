4. Passo 1 — Selecionar Período

Acesse Conciliações → Conciliar Período no menu lateral.

Tela inicial de "Conciliar Período" — selecione a empresa e informe a data-base antes de escolher a conta

4.1 Selecionar Empresa e Data-Base

No campo Empresa, selecione a empresa que será conciliada. A lista exibe apenas as empresas às quais você tem acesso.

No campo Data-Base da Conciliação, informe o último dia do mês de referência.

Exemplo: para conciliar Janeiro/2026, informe 31/01/2026. Use o botão "Mês Atual" para preencher automaticamente.

⚠️
O sistema valida a data automaticamente. Uma mensagem em laranja é exibida se a data não for o último dia do mês: "Informe o último dia do mês (ex: 31/12/2025, 30/11/2025)". As contas são carregadas normalmente mesmo com o aviso.
SÃO MIGUEL PARTICIPAÇÕES · 31/01/2026 — 268 contas conciliáveis listadas automaticamente após a seleção

4.2 Selecionar Conta e Tipo de Conciliação

Após selecionar empresa e data, o sistema carrega a lista de Contas Contábeis Conciliáveis na hierarquia do plano de contas. Identifique a conta que deseja conciliar e clique no botão "Conciliar".

Lista de contas contábeis — contas com o badge verde "Conciliável" possuem o botão "Conciliar"; contas já efetivadas exibem "✓ Efetivada"

Ao clicar em "Conciliar", o sistema abre um modal de seleção do tipo de conciliação em até 3 etapas:

Etapa 1 — Tipo: Escolha entre Financeiro (A Receber / A Pagar / Bancária) ou Estoque.

Etapa 2 — Ativo ou Passivo (somente para Financeiro): selecione ATIVO para Contas a Receber ou PASSIVO para Contas a Pagar.

Etapa 3 — Subtipo do Ativo (somente para Ativo): escolha BANCO para Conciliação Bancária ou CONTAS RECEBER para A Receber.

Etapa 2 — ATIVO (Contas a Receber) ou PASSIVO (Contas a Pagar)
Etapa 3 — BANCO (Conciliação Bancária) ou CONTAS RECEBER (títulos a receber)

5.1 Via API Protheus (recomendado)

O sistema busca os dados diretamente no Protheus, sem necessidade de exportar arquivos manualmente.

Na tela de conciliação, clique no botão "Parâmetros Protheus" (ícone de engrenagem) ao lado da base que deseja configurar.

Uma janela de parâmetros será aberta. Preencha os campos — Data Fim é sempre obrigatório. Os demais são filtros opcionais.

Confirme. Os dados serão buscados automaticamente no momento do processamento.

ℹ️
A URL e as credenciais do Protheus são configuradas pelo administrador. Se precisar apontar para um ambiente diferente (homologação), informe a URL do Protheus no campo disponível no dialog.

5.2 Via Arquivo Excel (alternativa)

Caso a integração com o Protheus não esteja disponível:

Exporte o relatório correspondente do Protheus em formato .xlsx.

Arraste o arquivo para a área de carregamento ou clique para selecionar.

Formatos aceitos: .xlsx, .xls, .csv — tamanho máximo: 50 MB. O arquivo é lido localmente no seu computador.

6. Passo 3 — Processar

Com as três bases configuradas, clique em "Processar Conciliação".

O sistema executa automaticamente:

  1. Busca os dados nas APIs do Protheus (quando configurado via parâmetros)
  2. Normaliza os dados de cada base — padroniza códigos, nomes de colunas e valores
  3. Faz o merge entre financeiro e contábil pelo código do cliente/fornecedor
  4. Calcula as diferenças (valor absoluto, percentual e classificação)
  5. Busca os lançamentos individuais no razão geral (CTBR480) para a análise detalhada
ℹ️
O processamento pode levar alguns segundos a mais quando os dados são buscados via API Protheus, dependendo do volume de registros e da latência com o servidor.

7.3 Análise Detalhada por Código

Para cada código com divergência, o sistema exibe os lançamentos individuais encontrados no razão geral (CTBR480), permitindo identificar exatamente quais lançamentos causam a diferença.

Cada lançamento mostra:

  • Data do lançamento
  • Histórico / descrição
  • Débito, Crédito e Saldo Atual
  • Status: VERDE (conciliado) ou VERMELHO (divergente)
  • Classificação: CONCILIADO · SÓ_FINANCEIRO · SÓ_CONTABILIDADE · DIVERGENTE_VALOR

8. Passo 5 — Efetivar a Conciliação

Efetivar significa registrar oficialmente o resultado no histórico do sistema para fins de auditoria.

Após analisar e confirmar que o resultado está correto, clique em "Efetivar Conciliação".

Confirme a operação na janela de confirmação.

O sistema salva o resultado com data, hora, usuário e empresa. A conciliação fica disponível no histórico de Acompanhamento.

⚠️
Por padrão, o sistema só permite efetivar conciliações sem divergências. Se a empresa estiver configurada para aceitar divergências, um alerta será exibido antes da confirmação.
🗑️
Uma efetivação pode ser excluída pelo administrador em Conciliações → Acompanhamento. A exclusão remove permanentemente todos os dados do registro e é irreversível.

10. Outros Tipos de Conciliação

Conciliação A Receber

Compara a posição de títulos a receber (FINR130) com o balancete contábil (CTBR140) e o razão geral (CTBR480). No modal, selecione: Financeiro → Ativo → Contas Receber.

Conciliação A Receber — SÃO MIGUEL · CDA - DISTRIBUIDORA ARAGUAIA · 31/01/2026

Conciliação A Pagar

O fluxo é idêntico à A Receber, utilizando o FINR150 (posição de títulos a pagar) como base de origem. No modal, selecione: Financeiro → Passivo.

Conciliação A Pagar (FINR150) — SÃO MIGUEL · NIDERA SEMENTES LTDA · 31/01/2026

Conciliação Bancária

Compara o extrato bancário do Protheus (FINR470) com o razão contábil da conta bancária (CTBR400). No modal, selecione: Financeiro → Ativo → Banco.

Conciliação Bancária — SÃO MIGUEL · BANCO DO BRASIL 27985-4 · 31/01/2026

Conciliação de Estoque

Compara os saldos do Kardex (MATR900) com as NF-e importadas da SEFAZ no sistema. No modal, selecione: Estoque.
