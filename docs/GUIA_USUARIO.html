1. Acesso ao Sistema

1.1 Login

Acesse o sistema pelo navegador e informe seu e-mail corporativo e senha.

Tela de Login — informe e-mail e senha para entrar

Digite seu e-mail corporativo no campo E-mail.

Digite sua senha no campo Senha.

Clique em Entrar ou pressione Enter.

ℹ️
Usuários administradores são direcionados ao Dashboard. Usuários comuns vinculados a mais de uma empresa verão a tela de seleção de empresa antes do Dashboard.

1.2 Esqueci minha senha

Na tela de Login, clique em "Esqueci minha senha".

Tela de Recuperação de Senha

Informe o e-mail cadastrado.

Clique em Enviar link. Você receberá um e-mail com o link de redefinição.

Acesse o link no e-mail e defina uma nova senha. O link expira em 30 minutos.

2. Dashboard

Dashboard — visão geral com menu lateral e métricas da empresa

3. Módulo de Conciliação

O módulo de conciliação compara os saldos registrados no sistema financeiro (Protheus) com os saldos contábeis, identificando automaticamente divergências.

Fluxo resumido

1
Selecionar Período — empresa, data-base e conta contábil
↓
2
Configurar fontes de dados — parâmetros da API Protheus (FINR130/150, CTBR140, CTBR480)
↓
3
Processar — sistema busca, normaliza e calcula as diferenças automaticamente
↓
4
Analisar resultado — resumo, tabela de diferenças e análise detalhada por código
↓
5
Efetivar — registra oficialmente no histórico para auditoria

3.1 Passo 1 — Selecionar Período

Acesse Conciliações → Conciliar Período no menu lateral.

Conciliar Período — selecione empresa, data-base e conta contábil

Selecione a Empresa no dropdown.

A lista exibe apenas as empresas às quais você tem acesso.

Informe a Data-Base da Conciliação — deve ser sempre o último dia do mês (ex.: 30/04/2026).

Use o botão "Mês Atual" para preencher automaticamente.

Após selecionar a empresa e a data, a lista de Contas Contábeis disponíveis será carregada abaixo. Escolha a conta que deseja conciliar.

Selecione o tipo de conciliação: A Receber, A Pagar, Bancária ou Estoque.

O sistema abrirá a tela de processamento correspondente.

⚠️
A data-base deve ser o último dia do mês. O sistema exibe uma mensagem de alerta em laranja caso a data informada não seja válida.

3.2 Passo 2 — Configurar Fontes e Processar

Após selecionar o período, a tela de conciliação é aberta com as três bases de dados que precisam ser configuradas:

BaseRelatório ProtheusO que contém
Origem (Financeiro)FINR130 (A Receber) ou FINR150 (A Pagar)Posição dos títulos por cliente/fornecedor
Contábil FiltradoCTBR140 — BalanceteSaldo contábil da conta selecionada
Contábil Geral (Razão)CTBR480 — Razão GeralTodos os lançamentos da conta para análise detalhada

Configurar via API Protheus (recomendado)

Clique no botão "Parâmetros Protheus" (ícone de engrenagem) ao lado da base desejada.

Preencha os parâmetros: Data Fim é obrigatório. Os demais (conta, filial, item) são opcionais e servem para filtrar os dados.

Confirme. Os dados serão buscados automaticamente no Protheus ao processar.

Configurar via arquivo Excel (alternativa)

Exporte o relatório do Protheus em formato .xlsx.

Arraste o arquivo para a área de carregamento ou clique para selecionar.

Formatos: .xlsx, .xls, .csv — máximo 50 MB.

✅
Após configurar as três bases, clique em "Processar Conciliação". O sistema busca os dados, normaliza, faz o merge e calcula as diferenças automaticamente.

3.3 Passo 3 — Analisar o Resultado

O resultado é exibido em três seções:

Resumo Geral

CardO que mostra
Total de registrosQuantidade total após o cruzamento
ConciliadosRegistros com diferença ≤ R$ 0,01 OK
Com divergênciaRegistros acima do threshold DIVERGENTE
Taxa de sucesso% conciliados sobre o total

Tabela de Diferenças

Tabela paginada com todos os registros. Use os filtros para localizar itens específicos:

FiltroOpções
BuscaPor código ou nome do cliente/fornecedor
StatusOK (conciliado) / Com Diferença
OrigemAmbos / Só Financeiro / Só Contabilidade
Itens por página10 / 20 / 50 / 100

Análise Detalhada

Para cada código com divergência, o sistema exibe os lançamentos individuais do razão geral (CTBR480). Cada item mostra:

  • Data, histórico, débito, crédito e saldo atual
  • Status: VERDE conciliado ou VERMELHO divergente
  • Classificação: CONCILIADO · SÓ FINANCEIRO · SÓ CONTABILIDADE · DIVERGENTE_VALOR

3.4 Passo 4 — Efetivar a Conciliação

Após confirmar que o resultado está correto, clique em "Efetivar Conciliação" para registrá-la no histórico.

⚠️
Por padrão, o sistema só efetiva conciliações sem divergências. Se a empresa permitir efetivação com divergências, um aviso é exibido antes da confirmação.

3.5 Acompanhamento de Fechamentos

Acesse Conciliações → Acompanhamento para visualizar o histórico de todas as conciliações efetivadas.

Acompanhamento de Fechamentos — histórico de conciliações por empresa e período

Selecione a Empresa, Ano e Mês.

Clique em Buscar. O sistema lista todas as conciliações efetivadas no período.

Clique em qualquer registro para ver o detalhe completo ou fazer o download do arquivo Excel.

🗑️
A exclusão de uma efetivação é permanente e remove todos os dados do registro. Disponível apenas para administradores.

4. Cadastros

4.1 Empresas

Acesse Cadastros → Empresas para gerenciar as empresas do sistema.

Cadastro de Empresas — listagem com filtros e estatísticas de total/ativas/inativas

Criar nova empresa

Clique em "Nova Empresa" (ou pressione Ctrl+N).

Preencha Nome (razão social) e CNPJ. O CNPJ é formatado automaticamente e validado pelos dígitos verificadores.

Defina o Status (Ativo/Inativo) e clique em Salvar.

Certificado Digital (para importação de NF-e)

Na listagem, clique no ícone de certificado na linha da empresa.

Clique em Upload de Certificado e selecione o arquivo .pfx.

Informe a senha do certificado e salve.

AçãoComo fazer
Buscar empresaCampo de busca por nome ou CNPJ
Filtrar por statusDropdown "Status": Todos / Ativos / Inativos
EditarÍcone de lápis na linha
ExcluirÍcone de lixeira (remove todos os dados vinculados)
Atualizar listaBotão "Atualizar" ou Ctrl+R

4.2 Plano de Contas

Acesse Cadastros → Plano de Contas para gerenciar as contas contábeis da empresa.

Plano de Contas — gerenciamento de contas contábeis com seletor de empresa e importação

Importar via Balancete (recomendado)

Selecione a Empresa no seletor.

Clique em "Importar Balancete" e selecione o arquivo Excel exportado do Protheus (CTBR140).

O sistema mapeará as colunas automaticamente e importará a estrutura hierárquica do plano.

Criar conta manualmente

Clique em "Nova Conta" (ou Ctrl+N).

Preencha: Conta Contábil, Descrição, Tipo (Ativo/Passivo/Receita/Despesa/Patrimônio), Conciliável e Conta Superior (para hierarquia).

Clique em Salvar.

ℹ️
Somente contas marcadas como Conciliável aparecem para seleção na tela de Conciliar Período.

5. Módulo de Estoque

O módulo de estoque controla o saldo de produtos com base nas NF-e importadas diretamente da SEFAZ.

ℹ️
Fórmula do saldo: Saldo Final = Saldo Inicial + Entradas − Saídas + Ajustes

5.1 Produtos

Acesse Estoque → Produtos para cadastrar e gerenciar os produtos da empresa.

Produtos — listagem com estatísticas de total/ativos/inativos e busca por descrição, código ou NCM

Criar produto

Clique em "+ Novo Produto".

Preencha: Código Interno (único por empresa), Descrição, NCM, Unidade de Estoque e Status (Ativo).

Clique em Salvar.

5.2 De-Para (Vínculo Produto × Fornecedor)

Acesse Estoque → De-Para para configurar a equivalência entre o código do produto no fornecedor e o código interno da empresa.

De-Para — vínculo entre produto interno e código do fornecedor com fator de conversão

Criar vínculo

Clique em "Novo Vínculo".

Selecione o Produto (código interno), informe o CNPJ do Fornecedor e o Código do Produto no Fornecedor.

Defina o Fator de Conversão e a Operação (Multiplicar/Dividir). Exemplo: fornecedor vende em caixas de 12 → fator 12, multiplicar.

Clique em Salvar.

✅
Com o De-Para configurado, ao importar NF-e o sistema vincula automaticamente os itens ao produto interno e aplica o fator de conversão na quantidade.

5.3 Importação de NF-e

Acesse Estoque → Importar NF-e para buscar notas fiscais diretamente na SEFAZ usando o certificado digital da empresa.

Importação NF-e — busca na SEFAZ com certificado digital, listagem de entrada e saída

Importar notas

Selecione o Certificado / CNPJ da empresa.

Informe a Data Início e Data Fim do período.

Clique em "Buscar na SEFAZ". A importação ocorre em segundo plano — aguarde o indicador de progresso.

Após concluir, clique em "Atualizar Lista" para ver as NF-e importadas nas abas Entrada e Saída.

Vincular itens pendentes

Itens sem De-Para configurado ficam com status VÍNCULO PENDENTE. Para vincular manualmente:

Na aba Entrada ou Saída, localize o item com status pendente.

Clique no ícone de vínculo e selecione o produto interno correspondente.

Confirme. O saldo do período é atualizado automaticamente.

5.4 Saldo de Estoque

Acesse Estoque → Saldo para visualizar a posição atual do estoque por produto.

Saldo de Estoque — posição por produto no período, com opções de reprocessar e exportar
ColunaDescrição
Saldo InicialSaldo final do mês anterior
EntradasNF-e de entrada do período
SaídasNF-e de saída do período

ℹ️
Use o botão "Reprocessar" para recalcular todos os saldos do período (útil após vincular itens ou importar novas NF-e).

5.5 Movimentações

Acesse Estoque → Movimentações para ver o histórico detalhado de todas as movimentações de um produto.

Movimentações — histórico detalhado com filtros por empresa, produto, período e tipo
TipoOrigemEfeito

5.6 Fechamento de Períodos

Acesse Estoque → Fechamento para fechar ou reabrir períodos.

Fechamento de Períodos — status mensal com opções de fechar e reabrir

Fechar período

Selecione a empresa e o período desejado.

Clique em "Fechar Período" e confirme.

⚠️
Após o fechamento, ajustes manuais não são permitidos no período. O sistema também fecha automaticamente o mês anterior no dia 01 de cada mês às 02:00.

Reabrir período

Se necessário corrigir dados, localize o período na lista e clique em "Reabrir". Use com cautela — pode impactar o encadeamento de saldos dos meses seguintes.

6. Administração

A área de administração é acessível apenas para usuários com perfil Administrador.

6.1 Gestão de Usuários

Acesse Administração → Usuários.

Gestão de Usuários — CRUD com filtros por status (ativo/inativo) e tipo (admin/comum)

Criar usuário

Clique em "+ Novo Usuário".

Preencha nome, e-mail, senha e tipo (admin/comum).

Salve e, em seguida, vincule o usuário às empresas que ele poderá acessar clicando no ícone de empresas na linha do usuário.

Para cada empresa vinculada, defina o perfil de acesso.

AçãoComo fazer
Buscar usuárioCampo de busca por nome ou e-mail
Filtrar por statusDropdown "Status": Todos / Ativo / Inativo
Filtrar por tipoDropdown "Tipo": Todos / Admin / Comum
Ativar/InativarToggle de status na linha do usuário
Editar dadosÍcone de lápis
Gerenciar empresasÍcone de empresa na linha

6.2 Perfis de Acesso

Acesse Administração → Perfis para visualizar e gerenciar os perfis de acesso.

Perfis de Acesso — lista de perfis com indicação de perfis do sistema (não editáveis)

Perfis definem quais funcionalidades cada usuário pode acessar dentro de cada empresa. Perfis do sistema são criados automaticamente e não podem ser alterados.

ℹ️
Um mesmo usuário pode ter perfis diferentes em empresas diferentes. O perfil é definido no momento da vinculação do usuário à empresa.
